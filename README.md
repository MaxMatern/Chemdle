# Chemdle ⚗️
**Daily Periodic Table Guessing Game**

Chemdle is an interactive daily chemical element guessing game inspired by Wordle. Deduce the secret mystery element each day using 8 comparative scientific attributes including category, period & group coordinates, orbital block, standard state, atomic mass, electronegativity, and melting point.

## Features
- **Daily Mystery Element**: Every day at midnight UTC, a new secret element is unlocked for all players worldwide.
- **8 Comparative Attributes**: Exact matches (green), partial/close matches (yellow), and directional arrows (↑/↓) guide deduction.
- **Interactive Periodic Table (Easy Mode)**: Visual table highlighting surviving candidates that fit all clues while dimming eliminated elements.
- **Bilingual Support (English & German)**: Switch between English and German in Settings, with full IUPAC element names, real-world applications, and localized gameplay.
- **Rich Chemistry Insights**: Click any element to discover its primary real-world application, discovery history, and electron configuration.
- **Offline & Persistent**: Saves gameplay statistics, current streak, and custom settings locally in your browser.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to play locally.
